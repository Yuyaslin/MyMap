# 台灣旅遊景點互動地圖 (Taiwan Travel Guide)

本專案是一個輕量、免安裝且支援響應式設計（RWD）的網頁應用程式，旨在提供使用者直覺且順暢的台灣景點探索體驗。透過地圖與卡片列表雙向互動，幫助使用者快速尋找、篩選並規劃個人的旅遊行程。

### ✨ 核心功能
* **多維度交叉篩選**：支援依「地區」（北部、中部、南部、東部、離島）與「景點主題」（自然風光、歷史人文、網美打卡等）快速分類，並結合實時關鍵字搜尋。
* **動態地圖與即時定位**：整合 Leaflet 地圖，地圖標記（Marker）與卡片列表即時聯動，並支援地理位置定位（Geolocation）功能。
* **個人化行程收藏**：提供「我的行程」側邊抽屜，使用者可一鍵收藏景點、管理清單，資料將自動儲存於瀏覽器（Local Storage）。
* **詳細景點資訊 Modal**：包含景點評分、建議停留時間、門票費用、特色亮點與一鍵開啟 Google 導航功能。

### 🛠️ 技術架構
專案採無後端（Serverless）架構設計，整合 Tailwind CSS 提供簡約質感視覺，結合原生 JavaScript 操作 DOM 與資料狀態管理，確保極佳的載入速度與跨裝置瀏覽體驗。
